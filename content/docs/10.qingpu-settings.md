# Qingpu User Settings API

This module provides a theme-private PostgreSQL settings bucket for the `qingpu` theme. It stores per-user workbench preferences in a single `qingpu_settings` table instead of scattering new global keys into APayShop's `settings` table.

## Setup

1. Configure `QINGPU_DATABASE_URL` or reuse `DATABASE_URL`.
2. Execute the SQL file at `app/themes/qingpu/database/settings.sql`.
3. Call `/api/qingpu/listing/settings` from the listing workbench.

## Storage Rules

- Settings are isolated by `user_id`.
- The root JSON document lives in `qingpu_settings.settings`.
- Listing model preferences are currently stored under `listing.modelSettings`.
- Future listing, collect, publish, or workflow preferences should continue to expand the same JSON bucket instead of creating one-off tables.

## Notes

- `imageGenSize` supports: `auto`, `1008x1344`, `1024x1536`, `768x1024`, `1024x1024`, `1536x1024`
- `imageGenQuality` and `videoGenQuality` support: `auto`, `low`, `medium`, `high`
- `imageProviderProfiles` is optional and stores reusable image presets; `activeImageProfileId` points to the current preset
- `offerIdPrefix`, `exchangeRate`, `commissionRate`, and related numeric fields store the default pricing inputs shared by Dash and the web settings page
- `translationGlossary` stores user-managed fixed terminology and stays separate from the local runtime `translationMemory` cache
- Empty model names are allowed and mean "fall back to the general model or future workflow defaults"
