# Qingpu AINode Site Data

Qingpu exposes two authenticated, read-only aggregation endpoints for its user center. APay resolves the current Qingpu user to the corresponding AINode account on the server and forwards only the small aggregate response required by the page. AINode integration tokens and internal user identifiers are never returned to the browser.

Both endpoints accept either the APay user session cookie or an active Qingpu tenant key in `Authorization: Bearer <tenant-key>`.

## Dashboard

- **Endpoint**: `/api/qingpu/ainode/site/dashboard`
- **Method**: `GET`
- **Authentication**: Required

```json
{
  "code": 0,
  "data": {
    "monthlySpend": 12.5,
    "monthlySpendCents": 1250,
    "activeKeysCount": 2,
    "totalCallsThisMonth": 318,
    "activityHeatmap": [{ "date": "2026-07-29", "count": 18 }],
    "usage": { "inputTokens": 12000, "outputTokens": 3600 },
    "quota": { "limit": 100000, "used": 15600, "percentage": 16 }
  }
}
```

The response contains only the 30-day activity aggregate needed by the dashboard. It does not include API keys, request logs, prompts, or user profiles.

## Wallet

- **Endpoint**: `/api/qingpu/ainode/site/wallet`
- **Method**: `GET`
- **Authentication**: Required

```json
{
  "code": 0,
  "data": {
    "funded": 20,
    "fundedCents": 2000,
    "spent": 7.5,
    "spentCents": 750,
    "available": 12.5,
    "availableCents": 1250,
    "sub": 5,
    "subCents": 500,
    "grant": 2.5,
    "grantCents": 250,
    "points": 0,
    "pointsCents": 0,
    "cash": 5,
    "cashCents": 500,
    "subExpiresAt": "2026-08-29T00:00:00Z"
  }
}
```

The endpoint returns only wallet totals and balance buckets. Transaction histories remain paginated through their dedicated endpoints and are not embedded here.

Concurrent dashboard and wallet requests share one in-flight AINode identity lookup. Successful mappings are cached for 10 minutes with a bounded in-memory cache. Identity resolution times out after 10 seconds and AINode site data requests time out after 15 seconds.
