# Visitor Analytics API

All endpoints in this module require an authenticated administrator session and return timestamps as UTC ISO-8601 strings.

## Get Visitor Details

Returns the complete visitor profile, linked user summary, aggregate behavior counts, related order summaries, and up to 100 recent events. Sensitive fulfillment data, payment credentials, and raw payment responses are not included.

**Endpoint:** `GET /api/admin/stats/visitors/:visitor_id`

**Path Parameters:**

- `visitor_id` (required): The full visitor ID stored in the `visitor_id` cookie and visitor analytics tables.

## Get IP Details

Returns aggregate statistics for one IP bucket within the selected reporting range, including all matching visitor identities, linked user summaries, observed location/device contexts, and up to 100 recent events.

**Endpoint:** `GET /api/admin/stats/ip-details`

**Query Parameters:**

- `ip`: The IP address to inspect. Required unless `local=1`.
- `local`: Set to `1` to inspect events whose IP is unavailable (`NULL`).
- `preset`: Reporting range preset (`today`, `yesterday`, `7d`, `30d`, or `90d`).
- `days`: Range size used by compatible custom presets.

**Response:**

```json
{
  "ip": "203.0.113.10",
  "range": { "preset": "today", "days": 1 },
  "stats": {
    "totalEvents": 32,
    "uniqueVisitors": 3,
    "registeredUsers": 1,
    "pageViews": 20,
    "productViews": 6,
    "checkouts": 2,
    "paid": 1,
    "auth": 1,
    "firstSeenAt": "2026-07-28T08:00:00.000Z",
    "lastSeenAt": "2026-07-28T10:00:00.000Z"
  },
  "visitors": [
    {
      "visitorId": "0d47f9aa-78a3-45c1-80d1-2d0e348923a7",
      "eventCount": 18,
      "firstTouch": "google",
      "user": { "id": 42, "email": "buyer@example.com" }
    }
  ],
  "visitorLimit": 100,
  "contexts": [],
  "recentEvents": [],
  "recentEventsLimit": 100
}
```

**Errors:**

- `400`: Invalid or oversized IP address.
