# Visitor Analytics API

All endpoints in this module require an authenticated administrator session and return timestamps as UTC ISO-8601 strings.

## Get Visitor Details

Returns the complete visitor profile, linked user summary, aggregate behavior counts, related order summaries, and up to 100 recent events. Sensitive fulfillment data, payment credentials, and raw payment responses are not included.

**Endpoint:** `GET /api/admin/stats/visitors/:visitor_id`

**Path Parameters:**

- `visitor_id` (required): The full visitor ID stored in the `visitor_id` cookie and visitor analytics tables.
