# Qingpu AINode 用户中心数据

Qingpu 为用户中心提供两个只读聚合接口。APay 在服务端把当前 Qingpu 用户映射到对应的 AINode 账号，只转发页面实际需要的小型聚合响应；AINode 集成令牌和内部用户 ID 永远不会返回浏览器。

两个接口都支持 APay 用户 Session Cookie，也支持通过 `Authorization: Bearer <tenant-key>` 携带有效的 Qingpu tenant key。

## 仪表盘

- **请求地址**: `/api/qingpu/ainode/site/dashboard`
- **请求方法**: `GET`
- **权限要求**: 已登录用户或有效 tenant key

```json
{
  "code": 0,
  "data": {
    "monthlySpend": 12.5,
    "monthlySpendCents": 1250,
    "activeKeysCount": 2,
    "totalCallsThisMonth": 318,
    "activityHeatmap": [{ "date": "2026-07-29", "count": 18 }],
    "usage": { "inputTokens": 12000, "outputTokens": 3600 },
    "quota": { "limit": 100000, "used": 15600, "percentage": 16 }
  }
}
```

响应只包含仪表盘所需的最近 30 天活动聚合，不包含 API Key、请求日志、Prompt 或用户画像。

## 钱包

- **请求地址**: `/api/qingpu/ainode/site/wallet`
- **请求方法**: `GET`
- **权限要求**: 已登录用户或有效 tenant key

```json
{
  "code": 0,
  "data": {
    "funded": 20,
    "fundedCents": 2000,
    "spent": 7.5,
    "spentCents": 750,
    "available": 12.5,
    "availableCents": 1250,
    "sub": 5,
    "subCents": 500,
    "grant": 2.5,
    "grantCents": 250,
    "points": 0,
    "pointsCents": 0,
    "cash": 5,
    "cashCents": 500,
    "subExpiresAt": "2026-08-29T00:00:00Z"
  }
}
```

响应只返回钱包汇总和余额分池。交易明细继续通过各自的分页接口按需获取，不会嵌入该响应。

仪表盘与钱包并发请求会复用同一个进行中的 AINode 身份解析。成功映射缓存 10 分钟，且内存缓存有容量上限；身份解析最多等待 10 秒，AINode 用户中心数据请求最多等待 15 秒。
