# Qingpu 用户设置 API

本模块为 `qingpu` 主题提供了一套私有 PostgreSQL 用户设置配置桶。它按用户维度把工作台偏好统一收口到 `qingpu_settings` 表中，而不是继续往 APayShop 全局 `settings` 表里追加零散键值。

## 初始化步骤

1. 配置 `QINGPU_DATABASE_URL`，或者直接复用 `DATABASE_URL`。
2. 执行 `app/themes/qingpu/database/settings.sql` 中的建表 SQL。
3. 通过 `/api/qingpu/settings` 读写 Qingpu 通用配置。

## 存储约定

- 配置按 `user_id` 隔离。
- 根 JSON 文档保存在 `qingpu_settings.settings` 中。
- 当前的模型偏好保存在 `listing.modelSettings` 下。
- 后续如果增加采集、发布或工作流相关偏好，也继续往同一个 JSON 配置桶里扩展，不再拆新的零散配置表。

## 1. 获取 Qingpu 基础设置

- **请求地址**: `/api/qingpu/settings`
- **请求方法**: `GET`
- **权限要求**: 已登录用户或 Bearer 租户 Key

该通用地址只验证身份与租户隔离，不要求用户开通 Listing 功能。旧地址 `/api/qingpu/listing/settings` 保留用于兼容尚未升级的客户端，但仍位于 Listing 功能权限域内。

## 说明

- `imageGenSize` 支持: `auto`、`1008x1344`、`1024x1536`、`768x1024`、`1024x1024`、`1536x1024`
- `imageGenQuality` 与 `videoGenQuality` 支持: `auto`、`low`、`medium`、`high`
- `imageProviderProfiles` 为可选字段，用于保存可复用的图片方案；`activeImageProfileId` 指向当前启用的方案
- `offerIdPrefix`、`exchangeRate`、`commissionRate` 等字段为铺货工作台默认定价参数，供 Dash 与官网设置页共用
- `translationGlossary` 为用户手工维护的固定术语表；它与本地运行期 `translationMemory` 缓存分开存储
- 模型名称允许留空，表示后续工作流可回退到通用模型或系统默认模型
