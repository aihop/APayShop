# 访客统计 API

本模块所有接口均要求管理员登录鉴权，时间字段统一返回 UTC ISO-8601 字符串。

## 获取访客详情

返回完整访客画像、关联用户摘要、行为累计统计、关联订单摘要，以及最多 100 条最近事件。接口不会返回履约密钥、支付凭证或支付原始响应等敏感数据。

**接口地址：** `GET /api/admin/stats/visitors/:visitor_id`

**路径参数：**

- `visitor_id`（必填）：保存在 `visitor_id` Cookie 和访客统计表中的完整访客 ID。
